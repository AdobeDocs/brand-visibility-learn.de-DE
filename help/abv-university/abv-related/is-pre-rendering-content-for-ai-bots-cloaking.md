# Deckt sich das Pre-Rendering von Inhalten für KI-Bots?

Nein. Durch das Pre-Rendering können KI-Agenten denselben Inhalt sehen, den ein Mensch sieht, und es folgt denselben Anweisungen, die Google für umfangreiches Client-seitiges JavaScript gibt.

## Für wen ist dieses Video bestimmt?

* Administratoren und Benutzer mit Bedenken bezüglich der KI-Optimierung und Verschleierung
* Teams, deren Seiten auf Client-seitiger JavaScript basieren

## Videoinhalt

In diesem Video erfahren Sie mehr über:

* Was Pre-Rendering bewirkt: Bereitstellung einer statischen HTML-Version, damit KI-Agenten die Seite sehen können
* Warum dies Googles eigene Anleitungen zum JavaScript-Rendering widerspiegelt
* Wie Googles Definition von Tarnung von Manipulationsabsicht abhängt
* Warum es keine Manipulation ist, Inhalte lesbarer zu machen
* Warum dies ein natürlicher Prozess mit geringem Risiko ist, wenn er im CDN ausgeführt wird
